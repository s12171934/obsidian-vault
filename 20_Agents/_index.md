# 20_Agents 인덱스

> 에이전트의 행동을 정의하는 도메인 (git 추적). 스킬 하나가 독립 공개 저장소 하나이며 `skills/<skill>/` 에 서브모듈로 들어온다.
> 훅·서브에이전트 정의 등은 `skills/` 의 형제 폴더로 확장한다.

상위: [[_Home]]

## 담는 것

- 스킬 서브모듈 `skills/<영문-케밥>/` — `SKILL.md`(트리거), `references/`(내부 실행 근거), `exports/`(공개 면)
- 공용 규칙을 전달하는 규칙 전용 스킬

## 담지 않는 것

- 볼트 자체 규칙의 본문 → [[00_Vault/_index|00_Vault]] (스킬은 본문을 가리키기만 한다)
- 이 환경에 맞춘 자동화 스크립트·프롬프트 → `30_Automations/`
- 도구의 규칙·스키마 → 해당 도구 저장소 (`40 → 20` 의존 금지)

## 구조 제약

- 스킬 저장소는 볼트 없이 단독 clone 해도 완결되어야 한다. 저장소 밖 경로를 참조하지 않는다.
- 다른 스킬은 스킬 이름으로, 도구는 `bin/` CLI 로만 의존한다 ([[폴더 구조 규칙]] §3).
- 저장소 밖에서 참조해도 되는 것은 스킬 이름과 `exports/` 뿐이다. `exports/EXPORTS.md` 에 공개 파일과 용도를 적는다.
- 도구 스킬 경로(`~/.claude/skills` 등)에는 서브모듈 폴더로의 심볼릭링크만 두고 복사하지 않는다.
- 스킬 저장소는 루트에 `README.md` 를 둔다. 아래 「목록」이 그 파일을 위키링크한다 (볼트 링크 예외, [[폴더 구조 규칙]] §3).
