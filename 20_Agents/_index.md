# 20_Agents 인덱스

> 에이전트의 행동을 정의하는 도메인 (git 추적). `90_Shared` 만 참조한다. 스킬 원본과 스킬이 읽는 작업 규칙을 둔다. 훅·서브에이전트 정의 등은 형제 폴더로 확장한다.

상위: [[_Home]]

## 담는 것

- 스킬 원본 `skills/<영문-케밥>/SKILL.md` 와 그 스킬 전용 `references/`
- 에이전트 작업 규칙 (구현 방식, 오케스트레이션 등)

## 담지 않는 것

- 볼트 자체 규칙의 본문 → [[00_Vault/_index|00_Vault]]
- 다른 도메인(30·40)과 함께 쓰는 규칙 → [[90_Shared/_index|90_Shared]]

## 구조 제약

- 스킬은 `20_Agents/skills/<skill>/SKILL.md` 로 볼트 루트에서 세 단계 깊이다. 스킬 파일 위치에서 볼트 루트를 계산하는 스크립트는 `../../..` 를 쓴다.
- 도구 스킬 경로(`~/.claude/skills` 등)에는 복사하지 않고 심볼릭링크로 연결한다 (실체는 볼트).
