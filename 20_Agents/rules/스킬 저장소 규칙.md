# 스킬 저장소 규칙

> 내 스킬 저장소(서브모듈)가 지켜야 할 조건을 정한다. 볼트 밖에서도 그대로 쓸 수 있는 독립 공개 저장소여야 한다.

## 단독 완결

- 스킬 저장소는 볼트 없이 단독 clone 해도 완결되어야 한다. 저장소 밖 경로를 참조하지 않는다.
- 실행 근거(절차·판정 규칙·스크립트)는 그 스킬 저장소가 소유한다. 내부 전용은 `references/`, 밖에서 참조해도 되는 것은 `exports/` 에 둔다.

## 의존과 공개 면

- 다른 스킬은 스킬 이름으로, 도구는 `bin/` CLI 로만 의존한다 ([[폴더 구조 규칙]] §3). 도구에 의존하면 `SKILL.md` 에 그 도구의 설치를 전제 조건으로 적는다.
- 저장소 밖에서 참조해도 되는 것은 스킬 이름과 `exports/` 뿐이다. `exports/EXPORTS.md` 에 공개 파일과 용도를 적는다.

## README 와 프론트매터

- 저장소 루트에 `README.md` 를 둔다. 목적, 설치 방법, 공개 면 요약을 담는다. [[20_Agents/_index|20_Agents 인덱스]] 의 「목록」이 이 파일을 위키링크한다 (볼트 링크 예외).
- 저장소 안의 `.md` 노트에는 볼트 프론트매터를 적용한다. `README.md` 의 `title` 은 저장소 이름으로 쓴다. `SKILL.md` 는 도구가 정한 형식을 따르므로 제외한다.
