# 스킬 로컬 연결 규칙

> 도구의 스킬 디렉터리를 볼트 `20_Agents/skills/` 에 연결하는 방식을 정한다. 볼트에서 스킬을 넣고 빼면 로컬 스킬 목록이 그대로 바뀌게 하는 것이 목적이다.
> 연결을 실제로 만드는 절차와 스크립트는 [[로컬 구성 규칙]] 이 정한다.

## 연결 방식

- 다른 프로그램이 쓰지 않는 도구 스킬 디렉터리는 **디렉터리째** `20_Agents/skills/` 로 링크한다 — 예: `~/.claude/skills`.
- 다른 프로그램이 관리하는 스킬 디렉터리는 디렉터리째 링크하지 않는다 — 예: `~/.agents/skills` (외부 스킬 설치 도구의 원본 사본과 Orca 가 설치하는 스킬이 함께 있다), `~/.codex/skills` (Codex 의 `.system` 이 있다). 그런 디렉터리에는 **내 스킬만 스킬별로** 링크한다.
- 링크는 볼트 밖에 두고 실체는 볼트에 둔다 (볼트 → 밖 방향). 스킬을 도구 경로에 복사하지 않는다.

## `skills/` 폴더

- `skills/` 에는 스킬 폴더만 둔다. 도구가 이 폴더의 하위 폴더를 스킬로 읽는다. `_index.md` 를 두지 않고, 목록은 [[20_Agents/_index|20_Agents 인덱스]] 가 맡는다.
- 도구가 남기는 부산물(`.trash/` 등 점으로 시작하는 폴더)은 무시 대상이다.
- 스킬을 끄려면 `skills/` 에서 뺀다 — 외부 스킬은 설치 도구로 제거하고, 내 스킬은 서브모듈을 해제한다.
- 볼트 안에서 밖을 가리키는 링크는 원칙상 금지지만, 외부 스킬 설치 도구가 `skills/` 에 만드는 링크는 예외로 허용한다. git 무시 대상이라 공개 저장소에 올라가지 않는다.
