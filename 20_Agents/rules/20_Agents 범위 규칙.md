# 20_Agents 범위 규칙

> `20_Agents/` 에 무엇을 두고 무엇을 두지 않는지 정한다. 배치 판정의 전체 순서는 [[폴더 구조 규칙]] 이 정한다.

## 담는 것

- `skills/<스킬>/` — 로컬에서 쓰는 스킬. 출처별 형태는 [[스킬 출처 관리 규칙]].
- 공용 규칙을 전달하는 규칙 전용 스킬.
- 훅·서브에이전트 정의 등 에이전트 행동 정의가 늘면 `skills/` 의 형제 폴더로 확장한다.

## 담지 않는 것

- 볼트 자체 규칙의 본문 → `00_Vault/rules/` (스킬은 본문을 가리키기만 한다)
- 이 환경에 맞춘 자동화 스크립트·프롬프트 → `30_Automations/`
- 도구의 규칙·스키마 → 해당 도구 저장소 (`40 → 20` 의존 금지)
