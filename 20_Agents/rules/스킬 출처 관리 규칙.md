# 스킬 출처 관리 규칙

> `20_Agents/skills/` 에 들어오는 스킬을 출처별로 어떤 형태로 두고, git 에서 어떻게 다루는지 정한다.

## 출처별 형태

| 출처 | 설치·관리 | `skills/` 안의 형태 | git |
| --- | --- | --- | --- |
| 내 스킬 (`s12171934` 공개 저장소) | 서브모듈 | 서브모듈 폴더 | 추적 (볼트 프론트매터 적용, `SKILL.md` 제외) |
| 외부 스킬 | `npx skills add <저장소> -g` | 설치 도구가 만든 링크(원본은 `~/.agents/skills/`) 또는 `--copy` 사본 | 무시 |
| 로컬 전용 스킬 | 직접 작성 | 일반 폴더 | 무시 |

- `.gitignore` 의 `/20_Agents/skills/*` 가 `skills/` 아래를 기본으로 무시한다. 외부·로컬 전용 스킬은 추가할 때 따로 설정하지 않는다.
- 내 스킬은 처음 등록할 때 한 번 `git submodule add -f https://github.com/s12171934/<skill>.git 20_Agents/skills/<skill>` 로 넣는다. 등록된 서브모듈은 무시 패턴의 영향을 받지 않는다.
- 외부 스킬은 대개 큰 저장소의 하위 폴더라 서브모듈로 넣지 않는다 (서브모듈은 저장소 전체만 붙일 수 있다).
- 내 스킬과 같은 이름의 외부 스킬이 이미 설치되어 있으면 `npx skills remove -g <스킬>` 로 지운 뒤 서브모듈로 등록한다.
- 내 스킬을 추가·제거하면 [[로컬 구성 규칙]] 의 스크립트를 다시 돌려 스킬별 링크를 맞춘다.

## 외부 스킬 설치 도구

- `npx skills` 는 항상 `-g`(전역)로 실행한다. 볼트 폴더 안에서 `-g` 없이 실행하면 볼트 루트에 `.claude/skills/` · `.agents/skills/` 가 생긴다.
- 외부 스킬의 목록·출처·버전의 원본은 설치 도구의 기록 파일(`~/.agents/.skill-lock.json`)이다. 볼트에 따로 적지 않는다. 백업이 필요하면 그 파일을 `30_Automations/` 의 비공개 저장소에 복사해 둔다.
- 갱신·제거는 설치 도구로 한다 (`npx skills update -g`, `npx skills remove -g`). 볼트 쪽 링크는 함께 바뀐다.
