# 00_Vault 인덱스

> 볼트 자체를 다스리는 규칙의 도메인. 규칙 노트는 `rules/`, 노트 템플릿은 `Templates/`, 볼트 구성 스크립트는 `scripts/` 에 둔다.

상위: [[_Home]]

## 규칙

- [[노트 작성 규칙]] — 프론트매터, 파일명, 태그 축, 링크, 본문 구조. 노트를 쓰기 전에 읽는다
- [[노트 분할 규칙]] — 최소 단위, 분할 기준, 길이 상한(200줄·8섹션), 결합 방법
- [[첨부 규칙]] — 첨부 원본은 R2, 노트에는 임베드 + 설명 줄
- [[폴더 구조 규칙]] — 도메인 구성, git 추적 경계와 의존 방향, 서브모듈 공개 면, 배치 판정, `_index`·`rules/` 구성
- [[변경 이력 규칙]] — 추적 문서는 git 커밋, 로컬 노트는 `CHANGE_LOG`
- [[공개 저장소 규칙]] — 추적 문서에 넣지 않는 것, 커밋 전 점검
- [[로컬 구성 규칙]] — 볼트를 새로 받은 기계에서 서브모듈과 스킬 링크를 구성하는 절차

## 목록

- `scripts/activate.sh` — 볼트 활성화 진입점. 아래 두 스크립트를 차례로 실행한다 ([[로컬 구성 규칙]])
- `scripts/local_index.py` — 로컬 전용 도메인의 `_index.md` 를 추적되는 `rules/` 로부터 만든다
- `scripts/link-skills.sh` — 서브모듈을 받고 도구 스킬 디렉터리를 `20_Agents/skills/` 로 연결한다
