# 00_Vault 인덱스

> 볼트 자체를 다스리는 규칙의 도메인. 노트 작성·정리·사용 규칙과 템플릿을 둔다.

상위: [[_Home]]

## 담는 것

- 노트 작성 규칙 (프론트매터, 파일명, 태그, 링크, 본문 구조)
- 폴더·도메인 구조와 이동 규칙
- 볼트 환경 세팅, 외부 표면 주입 컨텍스트
- 노트 템플릿 (`Templates/`)

## 담지 않는 것

- 에이전트가 볼트 밖에서 일하는 방식 → [[20_Agents/_index|20_Agents]]
- 볼트 규칙을 전달하는 스킬 파일 자체 → `20_Agents/skills/` (규칙 본문은 여기 둔다)

## 목록

- [[노트 작성 규칙]] — 프론트매터 스키마, 파일명, 태그 축, 링크, 본문 구조, 하지 않는 것. 노트를 쓰기 전에 읽는다
- [[노트 분할 규칙]] — 최소 단위, 분할 기준과 관심사 축, 길이 상한(200줄·8섹션), 나누지 않는 것, 결합 방법
- [[첨부 규칙]] — 첨부 원본은 R2, 노트에는 임베드 + 설명 줄, 올리지 않는 것
- [[폴더 구조 규칙]] — 최상위 도메인 구성, git 추적 경계와 의존 방향, 배치·경계 판정, 폴더 공통·연결·링크 규칙, 구조 변경 절차
