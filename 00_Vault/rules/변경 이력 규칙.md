# 변경 이력 규칙

> 볼트 노트의 개정 이력을 어디에, 어떤 형식으로 남기는지 정한다.
> git 추적 문서(`00_Vault` · 루트 진입 문서 · `20_Agents`·`40_Tools` 의 서브모듈 저장소 · 로컬 전용 도메인의 `rules/`)는 **커밋**이 이력을 갖는다. 로컬 전용 도메인(`10_Projects` · `30_Automations` · `50_Knowledge`)의 나머지 노트는 루트 `CHANGE_LOG.md` 한 곳에 이력을 모은다.

## 1. 원칙

- **노트는 현재 상태만** — 노트 본문과 요약 블록에는 개정 이유·경위·반영 내역을 쓰지 않는다.
- **추적 문서 → git 커밋** — 커밋 메시지 첫 줄에 무엇을 왜 바꿨는지 쓴다. 추적 문서에는 `## 변경 이력` 절을 두지 않는다.
- **로컬 노트 → `CHANGE_LOG`** — 개정 줄은 `CHANGE_LOG` 에만 쌓고, 노트에는 포인터 한 줄만 둔다.
- **스크립트가 만드는 로컬 `_index.md` 의 「규칙」 갱신은 개정으로 보지 않는다** — `rules/` 의 변경은 커밋에 이미 남는다.
- **개정의 날짜는 이력이 갖는다** — 노트의 `updated` 는 내용이 바뀐 날만 말한다.
- `CHANGE_LOG` 자체가 로컬 전용(git 무시)이라, 추적 문서는 `CHANGE_LOG` 를 위키링크로 가리키지 않는다.

## 2. 로컬 노트 쪽 형식

- 노트 맨 끝에 `## 변경 이력` 절을 두고 포인터 한 줄만 쓴다.

```markdown
## 변경 이력

- [[CHANGE_LOG#<이 노트의 title>]]
```

- **첫 개정 때 만든다** — 개정 이력이 없는 노트는 `## 변경 이력` 절을 두지 않는다. 신설은 개정이 아니다.
- 포인터 줄을 만들거나 고치는 것만으로는 `updated` 를 갱신하지 않는다.
- `CHANGE_LOG` 로의 섹션 링크는 섹션 링크 금지 규칙의 유일한 예외다.

## 3. CHANGE_LOG 쪽 형식

- 절 구조는 `## <도메인>` → `### <노트 title>` 두 단이다. `## <도메인>` 은 `10_Projects` · `30_Automations` · `50_Knowledge` 중 하나이며, 첫 노트 절이 생길 때 만든다.
- `###` 헤더는 노트의 `title` 과 **글자 그대로 같다.**
- 절의 첫 줄은 대상 노트 링크다 — `- 대상 — [[노트]]`. 파일명이 겹치면 전체 경로 + 별칭을 쓴다.
- 그 아래 **한 줄 = 한 개정** — `- YYYY-MM-DD — 무엇을 왜`. 두 문장을 넘기지 않고, **최신이 위다.**
- 사용자 지시로 한 개정은 줄 끝에 `(사용자 지시)` 를 붙인다.
- 경위를 길게 남겨야 하면 별도 로그 노트로 분리하고 개정 줄에서 링크한다.

## 4. 노트가 바뀔 때

- **개명** — `###` 헤더와 노트의 포인터를 같은 작업에서 함께 고친다.
- **로컬 도메인 사이 이동** — 절을 새 도메인의 `##` 아래로 옮기고 이동 사실을 개정 줄로 남긴다.
- **추적 도메인으로 이동** (예: 지식을 스킬·도구 저장소의 `references/`·`exports/` 로 승격) — 노트의 포인터를 지우고, `CHANGE_LOG` 절의 마지막 개정 줄로 이동 사실을 남긴다. 이후 이력은 커밋이 갖는다.
- **폐기·삭제** — 절은 지우지 않는다. 마지막 개정 줄로 폐기·삭제 사실과 대체 노트(없으면 없음)를 남긴다.

## 5. 면제

- **기록 노트는 `CHANGE_LOG` 기록을 면제한다** — 프로젝트 `작업 기록/` 레벨 폴더 안의 시점 스냅숏(구현 이력, 커밋 정리, 기각 로그, 리뷰, 자가 검수, 진행 로그).
    - 고쳐도 절과 포인터를 새로 만들지 않는다. `updated` 는 갱신한다.
    - 이미 있는 절과 포인터는 지우지 않는다.
- `CHANGE_LOG` 자신은 자기 절과 포인터를 두지 않는다.

## 6. CHANGE_LOG 문서의 지위

- 로컬 전용이다 (git 무시). 길이 상한을 적용하지 않는다.
- 세션 시작 시 로드하지 않는다. 특정 노트의 이력이 필요할 때 그 절만 읽는다 (`grep -n "^### <title>$"`).
- `_index` 체인에 넣지 않고 `_Home` 의 「로컬 전용 도메인」 절이 가리킨다.
- 규칙 문서(`00_Vault/`)의 개정은 사용자 승인을 받은 뒤 수행하고, 커밋으로 기록한다.
