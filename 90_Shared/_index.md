# 90_Shared 인덱스

> 재사용 부품의 기반 레이어. 도메인이 아니다. 실행 자산(스크립트·프롬프트)의 원본과, `20`·`30`·`40` 중 둘 이상이 쓰는 규칙·참조 문서를 둔다.
> 의존 방향의 맨 아래다 — 이 폴더의 문서는 다른 도메인을 참조하지 않는다.

상위: [[_Home]]

## 담는 것

- `rules/` 공용 규칙 문서
- `references/` 공용 참조 문서
- `scripts/` 실행 자산 원본 — 자동화·도구가 쓰는 스크립트·프롬프트 (사용처가 하나여도 여기 둔다)
- `references/` 에는 추적 문서가 인용해야 해서 `50_Knowledge/` 에서 올라온 지식도 둔다

## 담지 않는 것

- 한 도메인만 쓰는 규칙·참조 문서 — 두 번째 도메인이 실제로 쓰기 시작할 때 승격한다
- 이 환경의 설정값·상태 파일·비밀 → `30_Automations/` 또는 비밀 저장소
- 추적 문서가 인용하지 않는 지식 → `50_Knowledge/`

## 링크 규칙

- 공유 자산을 가리키는 방법(위키링크·실행 경로·볼트 → 밖 심볼릭링크)은 [[폴더 구조 규칙]] §7 을 따른다.
