# 40_Tools 인덱스

> 볼트 밖에서 도는 도구(대시보드, 로컬 서버, CLI 등)의 도메인 (git 추적). 도구 하나가 독립 공개 저장소 하나이며 `<tool>/` 에 서브모듈로 들어온다.

상위: [[_Home]]

## 담는 것

- 도구 서브모듈 `<tool>/` — `bin/`(CLI 진입점, 공개 면), `exports/`(스키마·프롬프트, 공개 면), `docs/`(명세 노트), `src/`(내부)
- 기능 기술서, 데이터 명세, 화면 문서 (`docs/`)

## 담지 않는 것

- 트리거로 도는 작업의 등록·상태 → `30_Automations/`
- 스킬의 규칙 — 도구는 스킬을 참조하지 않는다. 필요한 규칙은 도구가 소유한다

## 구조 제약

- 도구 저장소는 볼트 없이 단독 clone 해도 완결되어야 한다.
- 저장소 밖에서 참조해도 되는 것은 `bin/` 과 `exports/` 뿐이다. 30 과 스킬은 파일보다 CLI 로 의존한다.
- Obsidian 에는 `docs/` 만 노출한다 (`src/` · `node_modules/` · `vendor/` 는 제외된 파일로 등록).
- 도구 코드를 고치는 것은 볼트 내부 쓰기, 도구 저장소로 push 하는 것은 외부 쓰기다.
