# 40_Tools 인덱스

> 볼트 밖에서 도는 도구(대시보드, 로컬 서버, CLI 등)의 명세 도메인 (git 추적). `90_Shared` 만 참조한다. 볼트에는 문서만 두고 코드는 볼트 밖 저장소에 있다.

상위: [[_Home]]

## 담는 것

- 도구별 폴더 `<도구>/` — 기능 기술서, 데이터 명세, 화면 문서, 운영 기록
- 도구의 코드 위치(볼트 밖 경로)와 기동 방법

## 담지 않는 것

- 도구의 코드 자체 → 볼트 밖 (`~/tools/` 등). 볼트 세션은 쓰기 경계상 코드를 수정하지 않는다
- 트리거로 도는 작업 → `30_Automations/`
