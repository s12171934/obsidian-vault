# 도구 저장소 규칙

> `40_Tools/` 에 들어오는 도구 저장소(서브모듈)의 범위와 구성 조건을 정한다.

## 담는 것과 담지 않는 것

- 담는 것 — 도구 서브모듈 `<tool>/`: `bin/`(CLI 진입점), `exports/`(스키마·프롬프트), `docs/`(기능 기술서·데이터 명세·화면 문서), `src/`(내부 코드).
- 담지 않는 것 — 트리거로 도는 작업의 등록·상태(`30_Automations/`), 스킬의 규칙(도구는 스킬을 참조하지 않는다. 필요한 규칙은 도구가 소유한다).

## 저장소 조건

- 도구 저장소는 볼트 없이 단독 clone 해도 완결되어야 한다.
- 저장소 밖에서 참조해도 되는 것은 `bin/` 과 `exports/` 뿐이다. 30 과 스킬은 파일보다 CLI 로 의존한다.
- 루트에 `README.md` 를 둔다. 목적, 설치·기동 방법, 공개 면 요약을 담는다. [[40_Tools/_index|40_Tools 인덱스]] 의 「목록」이 이 파일을 위키링크한다 (볼트 링크 예외).
- 저장소 안의 `.md` 노트에는 볼트 프론트매터를 적용한다. `README.md` 의 `title` 은 저장소 이름으로 쓴다.

## 볼트에서 다룰 때

- Obsidian 에는 `docs/` 와 `README.md` 만 노출한다. `src/` · `node_modules/` · `vendor/` 는 "제외된 파일"로 등록한다.
- 도구 코드를 고치는 것은 볼트 내부 쓰기, 도구 저장소로 push 하는 것은 외부 쓰기다.
