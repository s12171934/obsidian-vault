# 50_Knowledge 범위 규칙

> `50_Knowledge/` 에 무엇을 두고 무엇을 두지 않는지 정한다.

## 담는 것

- 주제 폴더 `<주제>/` (같은 주제 노트가 3개를 넘으면 승격) 와 단발성 노트
- 스터디에서 배운 내용 정리 (진행 관리는 프로젝트 쪽)

## 담지 않는 것

- 에이전트·자동화·도구가 따르거나 실행하는 것 → 해당 스킬·도구 저장소 또는 `30_Automations/`
- 스킬·도구가 근거로 써야 하는 지식 → 그 저장소의 `references/`·`exports/` 로 옮긴다
- 언제까지 무엇을 끝내는 일 → `10_Projects/`
- 미분류 인박스 — 두지 않는다. 저장 시점에 주제를 정한다
